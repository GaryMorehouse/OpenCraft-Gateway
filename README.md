# OpenCraft Gateway

An open-source SmartCraft gateway for MerCruiser engines.

## Features

- SmartCraft CAN decoding
- Signal K
- MQTT
- REST API
- Grafana
- Future NMEA 2000 support

## Hardware

- Raspberry Pi Zero 2 W
- MCP2515 CAN Interface

## Status

🚧 Early Development
